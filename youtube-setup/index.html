YouTube Setup

Google Cloud project, OAuth client, audience, and configuration JSON

This guide covers the Google Cloud project, OAuth application, audience, and configuration JSON required before connecting SermonClip to YouTube. It ends with the in-app account connection step; uploading and exporting are self-explanatory once the connection is working.

1. Create or select a Google Cloud project

  1. Open Google Cloud Console and sign in with the Google account that owns or administers the church’s YouTube channel.
  2. Use the project picker at the top of the console to select an existing project or choose New Project.
  3. Give the project a recognizable name, such as SermonClip YouTube, and create it. Make sure the new project is selected before continuing.

2. Enable the YouTube API

  1. In the selected project, open APIs & Services → Library.
  2. Search for YouTube Data API v3.
  3. Open it and click Enable.

SermonClip uses this API for the connected channel, playlists, video uploads, thumbnails, metadata, and caption tracks.

3. Configure the Google Auth Platform

  1. Open Google Auth Platform for the same project.
  2. Complete the app configuration and branding fields. Use a recognizable app name such as SermonClip, and provide the requested support and developer contact information.
  3. Set the audience to External unless the Google account is part of a Google Workspace organization that owns the project.
  4. In Audience → Test users, add every Google account that will connect SermonClip while the app remains in Testing status.

Testing status is appropriate for an internal app. Google may expire refresh tokens for external apps left in Testing after a limited period, so reconnect if Google asks for authorization again.

4. Create the OAuth client and download its JSON

  1. In Google Auth Platform, open Clients (or Credentials, depending on the console view).
  2. Choose Create client and select Desktop app as the application type.
  3. Give the client a recognizable name, such as SermonClip Desktop.
  4. Create the client and click Download JSON immediately. This is the simplest and safest way to save the complete configuration file before closing the confirmation window.
  5. Keep the downloaded JSON private. Do not commit it to GitHub, place it in a shared website folder, or paste its contents into chat. The file is imported locally by each SermonClip installation.

Google normally lets you view the client ID and secret again from the client details, but you should not rely on reconstructing the configuration manually. If you close the window without downloading the JSON and cannot find a later download option, delete that client, create a new one, and download the new JSON immediately.

The downloaded file should be the Desktop application JSON generated by Google, not a service-account key or an API key. If you create a replacement OAuth client later, import the new JSON in SermonClip and reconnect the account.

5. Import the JSON and connect YouTube

  1. Open SermonClip and select YouTube Settings.
  2. Choose Import Google Configuration JSON and select the Desktop OAuth JSON downloaded in the previous step.
  3. Choose Connect YouTube.
  4. Complete Google’s consent screen in the browser and select the church’s YouTube channel if Google asks you to choose one.
  5. Return to SermonClip and confirm that the connected channel is shown in YouTube Settings.

SermonClip uses PKCE, a random OAuth state value, and a loopback-only callback listener. Tokens and resumable-upload records are stored in the macOS Keychain. The app does not read browser cookies or store a Google password.

Google restrictions and quota

  • The YouTube Data API has project-level quota limits. Review current usage in the project’s APIs & Services → Quotas page.
  • Custom thumbnails and some channel features depend on YouTube channel eligibility.
  • YouTube may impose separate upload, visibility, processing, or verification restrictions on a channel or project.
