SermonClip history

Changelog

Recent releases and retrospective development milestones

Releases

1.1.0 — Public-ready configuration

  • Removed the bundled Google OAuth configuration; users now import their own Desktop OAuth JSON in YouTube Settings.
  • Removed Stoney Creek-specific credential packaging from the generic build.

1.0.1 — Bundled bumper updates & cleanup

  • Automatically replaces changed protected bundled bumpers while preserving their IDs, names, defaults, and current selections.
  • Removed obsolete legacy naming and migration paths from the fresh deployment.
  • Updated bumper compatibility documentation and removed noisy test diagnostics.

1.0.0 — SermonClip 1.0! 🎉

  • Added delayed exact-track polling for YouTube subtitle uploads so temporary processing delays do not produce false failure notices.
  • Added background sermon and bumper loudness analysis with cached attenuation for bumper audio that is louder than the sermon. Quiet bumpers and sermon audio are never amplified or changed.
  • Updated the bundled Stoney Creek opening and closing bumper with the latest supplied SCB-Bumper.mp4.

Retrospective development milestones (prior to GitHub)

0.9.0 — First GitHub release

  • Packaged the Stoney Creek internal Apple Silicon DMG for macOS Tahoe 26+.
  • Included the bundled Stoney Creek Google OAuth configuration and default bumper.
  • Added automatic migration when the bundled Google configuration changes, with stored authorization cleared and reconnect status shown.
  • Added private GitHub release packaging, version metadata, and a reproducible DMG build script.
  • Added the DMG Applications-folder shortcut and drag-to-install layout.

0.8.0 — Release preparation and internal defaults

  • Standardized the SermonClip product name throughout the app and storage paths.
  • Added the internal Stoney Creek default opening and closing bumper and protected it from deletion.
  • Embedded light and dark sidebar logos and the app icon into the application bundle.
  • Added persistent user data migration for bumper libraries and description presets.
  • Added export-folder opening from the successful export notice, MP4-only and MP3-only export selection, and automatic MP4 requirements for YouTube uploads.

0.7.0 — Export performance and media compatibility

  • Added fast export that copies compatible source video without re-encoding.
  • Added source-derived adaptive H.264 bumper conversion and cached converted bumpers.
  • Preserved source resolution rather than upscaling lower-resolution recordings.
  • Added JPG bumpers with six-second display timing and correct MP3 omission.
  • Added export progress percentages, estimated time remaining, and shared export names for MP4, MP3, and SRT outputs.

0.6.0 — YouTube publishing workflow

  • Added Google OAuth sign-in using PKCE and secure macOS Keychain storage.
  • Added YouTube title, description, visibility, playlist, thumbnail, subtitle, and resumable upload controls.
  • Added reusable YouTube description presets and playlist refresh support.
  • Added upload diagnostics and improved handling of accepted YouTube uploads whose later API step fails.

0.5.0 — Subtitle workflow and local transcription

  • Added local subtitle generation, benchmarking, and completion estimates.
  • Added generated-subtitle review, local SRT import, preserved source text and grouping, and automatic spoken-sample matching.
  • Added manual subtitle adjustment, half-second timing controls, subtitle preview, and automatic selection of the first detected sermon cue.

0.4.0 — Waveform editing and sermon boundaries

  • Replaced coarse video scrubbing with waveform-based playhead control.
  • Added play/pause controls, persistent playhead time, detail mode, draggable scrubbing, and shaded selected-range highlighting.
  • Added sermon start, end, and subtitle-start markers with caret indicators.
  • Added boundary adjustment controls, nearby-pause refinement, manual takeover, and clear boundary validation.

0.3.0 — Bumpers, captions, and export workflow

  • Added persistent opening and closing bumper libraries with defaults, MP4 and JPG support, thumbnails, renaming, deletion confirmation, and protected bundled assets.
  • Added correct bumper timing in exported subtitles and MP4, MP3, and SRT export paths.
  • Added export-name validation, success notices, export-folder opening, and first-launch export-directory selection.

0.2.0 — Native application foundation

  • Established the native Apple Silicon SwiftUI macOS application.
  • Added local MP4 and SRT selection, native playback, parsing, validation, timestamp handling, manual sermon boundaries, and the initial export pipeline.
  • Added project persistence, security-scoped file bookmarks, and initial automated test coverage.

0.1.0 — Prototype foundation

  • Established the initial SermonClip prototype and project structure.
  • Proved the local-first workflow for a full service video, sermon selection, supplied subtitles, bumper insertion, and exported deliverables.
